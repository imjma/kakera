# Named Instagram Failed Sources are classified on every fetch

Instagram login walls and followers-only posts are named Failed Source reasons (`Instagram session expired` vs `Instagram post is followers-only`) on every capture path, classified only from the fetch error — not by assuming cookies work, and not by looking up the author. Direct captures print the reason. Inbox and Todoist report each class once per poll to `telegram.report_user_id`, listing the URLs, even when another Source Post saves the Capture; repeats are suppressed until the reason changes. Other Failed Sources stay silent if the group succeeds. Telegram Intake replies to the sender with the same reason. A followers-only post that Instagram still returns as a login wall is an expired session.
