# Primary source identifies composed captures

Composed Captures keep the first Submitted Source as the stable identity for
the Source Note, filename, and frontmatter, whether or not it resolves to a
verified Source Post. Additional Sources that resolve remain ordered body
sections and Failed Sources remain body-only diagnostics. This preserves the
existing single-source Capture format and makes recomposition predictable
without deleting reusable service/post Attachments; partial compositions are
allowed when at least one Submitted Source resolves with an image.
